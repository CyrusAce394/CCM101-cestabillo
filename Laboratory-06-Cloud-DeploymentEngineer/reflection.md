# Mission Reflection

This laboratory activity helped me gain a better understanding of the deployment and management of cloud applications using containers. While working with Docker Compose, I realized that having a configuration file makes deployment easier and more organized. Instead of using several commands one at a time, the required services and settings can be placed in one YAML file. In this way, I gained a better idea of how cloud engineers can save time while working with containers.

I also learned that configuration files have to follow specific formatting and structure requirements. YAML uses indentation to organize configuration settings, so even a small spacing error can prevent the deployment from running properly. This activity taught me that attention to detail is very important when working with cloud technologies.

I learned that it is important to use environment variables for information such as database passwords and usernames. This keeps the configuration flexible and avoids placing specific settings directly into the application configuration. I also gained experience using Docker Compose to configure Nextcloud and its database.

Deploying Nextcloud was an important experience because a complete cloud storage application could be configured in just a few minutes with the help of containers. It showed me that cloud deployment does not always require manually installing every component on a computer.

This activity gave me a better understanding of Cloud Computing. Now I know that cloud computing is not only about using online resources. It also involves containers, networking, databases, automation, configuration, and deployment. This mission helped me connect the knowledge I gained from previous activities with a real cloud application deployment.

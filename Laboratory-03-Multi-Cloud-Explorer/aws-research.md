# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is a broad, evolving cloud computing platform provided by Amazon. Launched in 2006, AWS offers over 200 fully featured services from data centers globally.

## Global Infrastructure
* **Regions:** 100+ Availability Zones within 30+ geographic regions worldwide.
* **Edge Locations:** 400+ Edge locations and Points of Presence (PoP) for low-latency content delivery.

## Cloud Management Console
The AWS Management Console provides a web-based portal to access, manage, and monitor all AWS cloud resources.

## Four Core Services
* **Compute:** Amazon EC2 (Elastic Compute Cloud) — Scalable virtual servers.
* **Storage:** Amazon S3 (Simple Storage Service) — Highly scalable object storage.
* **Database:** Amazon RDS (Relational Database Service) — Managed SQL database service.
* **Networking:** Amazon VPC (Virtual Private Cloud) — Isolated virtual network resources.

## Three Advantages
1. First-mover advantage with the broadest array of services and mature tools.
2. Extensive global network footprint and high availability.
3. Massive marketplace and vibrant community ecosystem.

## Typical Enterprise Use Cases
* Hosting large-scale global web applications.
* Enterprise data warehousing and big data analytics.
* Disaster recovery and multi-region backup systems.

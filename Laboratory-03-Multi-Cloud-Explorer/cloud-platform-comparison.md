## Core Analysis Questions

**1. Which cloud provider offers the broadest range of services?**  
Amazon Web Services (AWS) offers the broadest range of services in the public cloud market, featuring over 200 fully featured offerings. Its vast catalog spans foundational infrastructure to specialized technologies like quantum computing and satellite ground stations.

**2. Which provider best integrates with Microsoft technologies?**  
Microsoft Azure delivers the most seamless integration with Microsoft environments, software licenses, and development tools. It natively supports legacy workloads such as Active Directory (via Microsoft Entra ID), Windows Server, SQL Server, and Microsoft 365.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**  
Google Cloud Platform (GCP) is widely recognized as the leader in Kubernetes and cloud-native AI development. Because Google originally created Kubernetes and built frameworks like TensorFlow, GCP provides superior container orchestration via Google Kubernetes Engine (GKE) along with advanced data analytics and AI tools like Vertex AI and custom TPUs.

**4. Which cloud platform would you personally choose and why?**  
I would personally choose AWS due to its market-leading position, deep documentation, and extensive ecosystem support. Its sheer versatility allows developers to build almost any application architecture while acquiring skills that are universally in high demand across the IT industry.

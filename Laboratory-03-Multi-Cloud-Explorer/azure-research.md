# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a cloud computing service operated by Microsoft for application management via Microsoft-managed data centers. It was launched in 2010.

## Global Infrastructure
* **Regions:** Available in over 60 regions worldwide—more than any other cloud provider.
* **Availability Zones:** Multiple isolated locations within each region to ensure fault tolerance.

## Cloud Management Console
The Azure Portal is a unified web-based console that simplifies building, managing, and monitoring cloud assets.

## Four Core Services
* **Compute:** Azure Virtual Machines — On-demand, scalable computing resources.
* **Storage:** Azure Blob Storage — Unstructured object storage for cloud-native workloads.
* **Database:** Azure SQL Database — Fully managed relational database built on SQL Server.
* **Identity:** Microsoft Entra ID (formerly Azure Active Directory) — Cloud identity and access management.

## Three Advantages
1. Seamless integration with legacy Microsoft software, Active Directory, and Windows Server.
2. Flexible hybrid cloud capabilities with Azure Arc and Azure Stack.
3. Enterprise-focused compliance certifications and licensing benefits for existing Microsoft clients.

## Typical Enterprise Use Cases
* Migrating traditional Windows-based enterprise applications.
* Hybrid cloud environments combining on-premises data centers with cloud resources.
* Enterprise identity management and remote workforce management.

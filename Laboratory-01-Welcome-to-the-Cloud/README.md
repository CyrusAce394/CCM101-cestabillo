# Laboratory 1: Welcome to the Cloud

## Mission Overview
Completed onboarding as a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies. This activity focuses on cloud-hosted Linux system administration, command-line operations, and version control management using Git and GitHub.

## Objectives
- Access a cloud-hosted Linux environment via KillerCoda (KillerCoda, 2024).
- Explore fundamental Linux system commands, directory structures.
- Establish version control and portfolio documentation using Git and GitHub.

## Activities Performed
- Created a custom Linux user with root/sudo privileges.
- Gathered system telemetry including CPU, memory, and disk space statistics.
- Constructed organized workspace directory structures.
- Built and published a public GitHub portfolio repository.

## Linux Commands Used
- **User Management**: `useradd`, `passwd`, `usermod`, `su`
- **System Navigation & Telemetry**: `whoami`, `pwd`, `hostname`, `uname`
- **Hardware & Resource Diagnostics**: `lscpu`, `free`, `df`
- **File System Operations**: `mkdir`, `nano`, `cat`, `ls`

## Skills Learned
- Basic Linux system administration and permission handling.
- Navigating and executing tasks within Command Line Interfaces (CLI).
- Technical documentation writing adhering to Markdown and APA standards.

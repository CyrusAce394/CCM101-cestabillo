# Mission Reflection

In evaluating cloud infrastructure primitives, compute resources stand out as the most fundamental component[cite: 1]. Without processing power and memory, applications cannot execute business logic, process user requests, or interact with storage and network layers[cite: 1]. However, operating these components effectively relies heavily on Linux, which serves as the backbone of modern cloud computing[cite: 1]. Because Linux is lightweight, open-source, and secure, major cloud providers utilize it to power their underlying hypervisors, containerized environments, and enterprise virtual machines[cite: 1]. Its robust command-line tools enable engineers to inspect hardware specifications, monitor system performance, and automate cloud management tasks efficiently[cite: 1].

Before deploying any infrastructure, preparing technical documentation is essential[cite: 1]. Creating a clear blueprint ensures that architectural designs are thoroughly evaluated for security, scalability, and cost efficiency prior to spending capital[cite: 1]. Proper documentation minimizes system misconfigurations, provides troubleshooting guidelines, and establishes an audit trail necessary for team collaboration and compliance[cite: 1]. 

Through this laboratory activity, I developed practical skills in auditing server resources using essential Linux commands such as `lscpu`, `free -h`, `df -h`, and `ip a`[cite: 1]. Additionally, I learned to map physical hardware concepts to equivalent virtual services across major public cloud platforms like AWS, Azure, and GCP, while designing simple architecture diagrams and authoring structured Markdown reports[cite: 1].

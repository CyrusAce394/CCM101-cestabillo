# Major Public Cloud Provider Comparison

## Core Infrastructure Services

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform (GCP) |
| :--- | :--- | :--- | :--- |
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 / EBS | Azure Blob / Disks | Cloud Storage / Persistent Disk |
| **Networking** | Amazon VPC | Azure Virtual Network (VNet) | VPC Network |
| **Identity and Access Management (IAM)** | AWS IAM | Microsoft Entra ID | Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
AWS offers the broadest range of services because it was the pioneer in public cloud computing, giving it a longer head start to build out a massive, mature portfolio of specialized tools.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is recommended for Microsoft-centric organizations due to seamless native integration with Active Directory, Windows Server, Microsoft 365, and enterprise licensing discounts.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized for AI/ML and Kubernetes, benefiting from Google's internal development of Kubernetes and advanced data processing technologies.

### 4. What similarities did you observe among the three cloud providers?
All three providers share foundational infrastructure primitives—offering on-demand virtual compute engines, scalable block and object storage solutions, isolated virtual networks, and identity/access security controls[cite: 1].

# Security Audit Report

## Principle of Least Privilege (PoLP)

The Principle of Least Privilege is a security practice that gives users and applications only the permissions they need to perform their tasks. It is important in cloud computing because it prevents unauthorized access to sensitive data and reduces the risk of security breaches.

## Attack Surface

The attack surface refers to all possible entry points that attackers could use to access a virtual machine or server. These include open network ports, running services, user accounts, and applications that may contain vulnerabilities.

## Default Deny Policy

The Default Deny Policy blocks all incoming network traffic unless it is explicitly allowed by a firewall rule. This approach is safer because it prevents unknown or unauthorized connections instead of trying to identify and block individual attackers.

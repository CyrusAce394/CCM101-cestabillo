
# Laboratory 09 - Cloud Automation Engineer

## Mission Reflection

In this laboratory activity, I learned that automation can help speed up and simplify the management of cloud computing operations. Automation is necessary in cases when the number of cloud servers reaches several hundred because the repetition of identical tasks is associated with the need for constant supervision over each server.

Also, there are risks associated with the use of automation tools. An error in a script can result in the loss of data stored on the servers and the interruption of their work. In order to minimize the risks, one should test an automated script before its execution.

The creation of a Bash script is different from the creation of a Docker Compose YAML file in Laboratory 6. Whereas in the previous laboratory, the only focus was put on the description of services and their deployment in containers, Bash scripting is related to the execution of Linux commands and automation of operations.

Analyzing all laboratory activities from 1 to 9, I can conclude that my understanding of cloud computing has developed considerably. Initially, I learned that cloud computing as a method of storing information and accessing online services. However, through these laboratory activities, I have acquired knowledge on the structure of cloud computing, containerization, databases, deployment, monitoring, security, and automation of cloud computing operations.

Of all roles, I liked most that of a Cloud Automation Engineer since Bash scripting appeared to be an interesting and useful task. Specifically, I enjoyed the creation of an automated backup and configuration of a Cron job.

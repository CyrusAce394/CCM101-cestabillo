
# Automation Research

## 1. Bash Script
A Bash script is a text file containing Linux commands that can be executed automatically instead of typing each command manually. The `#!/bin/bash` line is called a shebang, and it tells the operating system to use the Bash interpreter to run the script.

## 2. Variables
Variables are used to store information such as folder paths, names, and dates so they can be reused throughout a script. For example, `$BACKUP_DIR` lets us refer to the backup directory without repeatedly typing its path, making the script easier to update and maintain.

## 3. Cron Job
A cron job is a scheduled task in Linux that automatically executes commands or scripts at specific times. It is important in cloud operations because it allows routine tasks like backups, maintenance, and monitoring to run consistently without manual intervention.

# Mission Reflection

This laboratory activity helped me get a better insight into the deployment and management of cloud applications in the form of containers. Working with Docker Compose, I realized that the if you know of a configuration file makes deployment easier and systematic. Instead of using several commands at a time, the required services and settings can be put in one YAML file. In this way, I got a better idea about how cloud engineers can save their time while dealing with containers.

Also, I learned that configuration files have to meet some formatting and structure requirements. YAML uses indentation to set the settings of configuration, so any insignificant space can make the deployment impossible to run. This activity taught me that cloud technologies is very impotant.

I learned that, it is important to use the environment variables to input such information as database passwords and usernames. In this way, the configuration will remain flexible and no need to put some particular settings in the configuration of the application. Also, I gained experience related to using Docker Compose to configure Nextcloud and its database.

Deploying of Nextcloud was a very important process, as a whole cloud storage application was able to be configured in just a few minutes through the help of containers. It became clear to me that there is no need for the installation of each and every component on a computer for cloud deployment.

This activity give me more understanding of Cloud Computing has expanded. Now i know that cloud computing is very userful in terms of using online resources. It involves such aspects as containers, networking, databases, automation, configuration, and deployment. This mission helped me integrate all knowledge received during the previous ones with the real-life application deployment.

# Laboratory 06 - Cloud Deployment Engineer

## Mission Overview

This activity focused on deploying Nextcloud and MariaDB using Docker Compose. The two containers worked together as a simple multi-tier cloud application.

## Objectives

- Understand multi-tier architecture.
- Create a `docker-compose.yml` file.
- Deploy Nextcloud and MariaDB.
- Practice basic Docker Compose commands.
- Learn the basics of Infrastructure as Code.

## Commands Executed

-bash
mkdir nextcloud-deployment
cd nextcloud-deployment
nano docker-compose.yml
cat docker-compose.yml
docker-compose up -d
docker-compose ps
docker-compose down

# Mission 5 Reflection

By doing this activity, I was able to learn about the use of object storage to accommodate millions of user photos in a storage. Also, I found out that object storage would be the best choice since it was designed for large amounts of data and scalability when more data becomes available. Every file was represented by an object with additional information and unique identifier.

The use of Docker was very convenient as well, since I could deploy the MinIO server without having to perform any installation and configuration manually. I just had to execute one `docker run` command which did everything else, including downloading the image, creation of the container, configuration of the port mapping and administrator account.

Also, I discovered the meaning of bucket in cloud storage. As a result of this activity, I created a `client-photos` bucket for storing files.

Large companies should have a ways for recovering their data in case of failure of the physical servers, with that they can use backups, replication and erasure coding, which provide for keeping additional copies or pieces of data and enable recovering from hardware failures.

Lastly, my skills with the Linux command line are continous growing. To begin with, there were some Docker and Linux commands unknown to me, however, after performing the activity, I felt much more confident executing commands, working with containers, and even with MinIO.

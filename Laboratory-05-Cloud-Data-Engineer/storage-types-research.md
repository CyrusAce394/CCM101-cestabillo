# Cloud Storage Types

| Storage Type       | Description                                          | Primary Use                        | Example   |
| ------------------ | ---------------------------------------------------- | ---------------------------------- | --------- |
| **Block Storage**  | Stores data in blocks.                               | Virtual machines and applications. | AWS EBS   |
| **File Storage**   | Stores data as files and folders.                    | Sharing files and documents.       | AWS EFS   |
| **Object Storage** | Stores files as objects with information about them. | Photos, videos, and backups.       | Amazon S3 |

## Why Object Storage?

Object Storage is a good choice for storing millions of photos because it can store large amounts of files. It also keeps the photos separate from the web server, making them easier to manage.
